## AI는 판단하고, 나는 조회와 입력을 맡는다

계좌 조회와 주문은 내가 앱에서 직접 처리하기로 했다. AI는 전달받은 계좌 정보와 직접 조사한 시장 자료로 판단하고, 종목·수량·가격·입력 기한이 정해진 지시서를 작성한다. 나는 그 내용을 입력하고 접수·체결 결과를 다시 전달한다.

이 프로젝트는 증권사 API 없이 운영한다. 이 결정은 실제 사용 가능한 실행 경로에 따른 것이며, 증권사의 모든 API 제공 여부를 독립적으로 확인했다는 의미는 아니다. 장중 요청에 수시로 대응할 수 있지만 언제나 즉시 입력할 수 있다고 가정하지 않는다.

## 지시와 체결은 따로 기록한다

주문 지시서를 만들었다고 주식을 보유한 것은 아니다. 앱에 주문이 접수됐는지, 일부만 체결됐는지, 남은 수량이 얼마인지 확인해야 한다. 결과 보고가 없으면 미입력이나 미체결로 단정하지 않는다.

입력 기한이 지났다고 이미 접수된 주문이 자동으로 취소되는 것도 아니다. 그래서 신규 주문에는 미체결 확인과 취소 계획도 함께 쓰도록 했다.

조회와 주문 입력은 운영 보조로 기록한다. 내가 시장 전망에 따라 종목·수량·가격·시점을 바꾸면 투자 의견 개입으로 구분한다. 이 구분이 있어야 AI의 판단과 사람의 실행이 결과에 어떻게 반영됐는지 설명할 수 있다.
