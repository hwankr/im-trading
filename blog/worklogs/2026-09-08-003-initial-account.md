## 시작 상태는 현금 1억 원

대회 참가를 완료했고, 보유 주식·미체결 주문·이전 거래가 없는 상태임을 확인했다. 주문가능금액은 계좌 화면의 다른 숫자로 대체하지 않고 별도로 확인했다.

| 항목 | 확인된 초기 상태 |
| --- | --- |
| 정산금액 | 100,000,000원 |
| 정산예수금 | 100,000,000원 |
| 현금 주문가능금액 | 100,000,000원 |
| 주식 총매입금액·총평가금액 | 각각 0원 |
| 보유 주식 | 없음 |
| 미체결 주문·이전 거래 | 없음, 사용자 확인 |

같은 1억 원으로 표시돼도 정산금액·정산예수금·주문가능금액은 서로 다른 항목이다. 세 값을 합쳐 자산 3억 원으로 계산하지 않는다.

## 아직 확인하지 않은 지표

주식잔고 화면의 평가손익은 0원, 0.00%였다. 이를 대회 중계실의 공식 누적 수익률로 옮기지는 않았다. 공식 수익률·순위·회전율·인정 종목·거래일수는 해당 화면을 확인하기 전까지 미확인으로 남겼다.

추가로 확인한 주문가능금액은 새 보고로 저장했다. 처음에는 몰랐던 값을 최초 기록에 소급해 넣지 않았다. 공개 원고에는 필요한 숫자만 옮겼다.
