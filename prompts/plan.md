# 최종 10위 수상 목표 · 고정 가격·유연한 진입 계획

## 2026-10-02 후속 정책 · 최종 수상 목표에 따른 유연한 판단

정책 ID: `policy-20261002-prize-objective-flexibility`. 최종 10위 이내 수상이 판단 기준이며 자산 방어만으로 독립적인 성공을 선언하지 않는다. 종료 시 11위와 200위는 모두 수상 목표 미달이라는 뜻에서 같다. 손실을 추구하거나 수상 확률·가격 근거를 조작하지 않는다.

신규 계획·명시적 버전 수정부터 종목 수·이벤트 편입·자산 감소에 따른 자동 신규 중지 제한과 고정 보유기간 선호를 폐지한다. 종목 수 늘리기·무조건 전액 투입·분산은 의무가 아니다. 촉매·가격 반영·비용 후 기여·실행 가능성을 함께 비교하며, 낮은 손익비나 불명확한 확률을 무시하거나 조작하지 않는다.

공식 원금의 50%(원금 1억원 기준 5천만원) 단일 종목 한도·현금 매수·취소 및 체결 대사·이미 발동한 청산은 유지한다. 기존 HLB·LS 주문과 2026-10-02 15:10 KST 청산, 오늘 기존 마감 및 사용자의 2026-10-06 일정은 자동 변경·연장하지 않는다. 아래 1차 정책의 추가 운영 제한 유지 부분은 이 후속 정책으로 대체한다.

## 2026-10-02 1차 정책 이력 · 운용 비중·손절 예산 제한 폐지

사용자가 원래 명시한 단일 종목 45%·최소 현금 10%·한 거래 계획 손절 예산 2%를 폐지하고, 연결된 전체 편입 90%·합산 계획 손절 예산 5%까지 사용자 승인 범위로 함께 폐지한다. 고정 권장 비중 범위도 적용하지 않는다. 신규 계획 또는 명시적으로 버전을 올린 수정본부터 적용하며, 기존 주문 수량·손절가·익절가·시간 청산·이미 발동한 청산은 변경하지 않는다.

당시 최대 동시 보유 3종목·발표 전 최초 이벤트 종목 40%·동일 이벤트 합산 70%·기준자산 대비 실제 10% 감소에 따른 신규 중지·재평가를 유지했다. 이 중 종목 수·이벤트 비중·자산 감소 자동 중지 제한은 후속 정책으로 대체한다. 공식 종목 한도·현금 매수(cash-only)·실제 주문가능현금·매수 미체결 전량 반영·비용 여유와 손절액·스트레스 참고 기록은 계속 유지한다.

2026-09-29 동일 이벤트 스트레스 손실 한도 폐지 이력은 유지한다. 그때 유지했던 운용 비중·계획 손절 예산 부분은 이번 변경으로 대체한다.

모의투자 전용이다. 목적은 원금 방어·회전율 채우기가 아니라 최종 10위 이내 수상이다. 기존에 확인된 손절·시간 청산이 먼저이며 수익·수상·체결을 보장하지 않는다.

## 2. 매수·보유·교체를 동시에 비교

- 최신 가격·거래량·시장·업종·공시와 출처·관측 시각·가격 종류를 확인한다. 과거 종가를 현재 호가로 쓰거나 사후 정보를 소급하지 않는다.
- 주도주·강한 업종·실적·수주 등 검증 가능한 촉매와 가격 반영을 비교한다. 인버스를 방어용 기본값으로 두지 않는다. 한 종목 보유 때문에 다른 종목의 매수를 막지 않는다.
- 후보별 유지 / 신규 / 교체 / HOLD / BLOCKED를 결정한다. 가격·종목 식별·호가 단위·거래 제한·핵심 근거가 부족한 후보는 개별 BLOCKED다. 한 후보의 미확인을 전체 계좌 관망으로 확대하지 않는다.
- 기존 보유의 촉매 약화·남은 상승 여력·비용 후 대안을 비교한다. 본전까지 기다리는 것을 보유 근거로 삼지 않는다. 교체가 낫다면 새 버전과 취소·실제 매도·신규 자금 사용 순서를 명시한다.
- 신규 매수가 없거나 현금 비중이 높다면 구체적인 최신 근거와 주요 탈락 후보를 짧게 설명한다. 이벤트 존재·기존 보유·막연한 불확실성만으로 일괄 관망하지 않는다. 근거 없는 의무 매수도 하지 않는다.

## 3. 가격·수량·계좌 기여

- 신규 후보·동시 보유 종목 수에 운영상 고정 상한을 두지 않는다. 각 종목의 진입 상한·손절은 원화 정수 하나씩, 익절은 확정 실행표로 정하고 실제 호가 단위와 `0 < 손절 < 진입 < 각 익절가`를 확인한다.
- 깊은 눌림만 고집하지 않는다. 확인 호가·변동성·스프레드·유동성·비용 후 손익이 맞으면 체결 우선 지정가를 선택한다. 지연·미확인 호가로 즉시 체결을 단정하거나 승률·체결 확률을 만들지 않는다.
- 수상에 필요한 수익률을 맞추려고 익절가를 역산하지 않는다. 진입 상한 반복 인상·무조건 시장가 전환·장중 VWAP·몇 분 뒤 재판단 같은 추가 조건을 떠넘기지 않는다.
- 공식 원금의 50%(원금 1억원 기준 5천만원) 단일 종목 한도를 지킨다. 이벤트 비중·고정 권장 비중 없이 촉매·비용 후 기여·공통 위험·다른 후보와의 교체를 비교해 수량을 정한다. 종목 수 늘리기·분산·무조건 전액 투입은 의무가 아니다.
- 실제 주문가능현금으로만 매수(cash-only)하며, 보유·매수 미체결 전량 체결 가능성과 동일 이벤트 합산 노출을 반영한다. 실제 주문가능현금·공식 종목 한도·실제 거래비용과 근거 있는 체결 여유가 허용하는 정수 수량을 사용하고 고정 10만원 버퍼를 강제하지 않는다. 미확인 매도대금·증거금 배수로 수량을 늘리지 않고, 취소 완료·취소 중 체결 대사·실제 매도·주문가능현금 확인 전 같은 자금을 재사용하지 않는다.
- 계획 손절액·합산 계획 손절액과 스트레스 시나리오는 가능한 최초 체결부터 다음 실제 점검·집행까지의 장중·갭·확인 지연을 포함해 계산·기록하는 참고 수치다. 신규·명시적 버전 수정 계획에서 폐지한 비중·손절 예산·스트레스 손실 상한을 수량 제한·진입 차단 조건으로 사용하지 않는다. 스트레스 변동률을 수량에 맞춰 임의로 낮추지 않는다. 실제 손실은 계획 손절액과 참고 시나리오보다 커질 수 있다.
- 기준자산과 실제 자산 감소는 출처·관측 시각·감소폭을 보고·기록하고 분석한다. 감소율만으로 신규 진입·분석을 자동 중지하거나 일시중지하지 않는다. 손실 뒤 기준점이나 기존 발동 청산을 지우지 않는다.
- 계획 지표: 익절수익률 `(익절/진입-1)*100`, 손절폭 `(1-손절/진입)*100`, 손익비 `(익절-진입)/(진입-손절)`. 비용 전 계획값이며 예측 수익·실현 손익·손실 상한이 아니다.
- 손익비를 단독 탈락 기준으로 쓰지 않는다. 낮은 손익비·불명확한 확률은 촉매·가격·비용·실패 시나리오와 함께 설명하며 무시하거나 조작하지 않는다. 방어 가능한 확률 근거가 없으면 null이다.
- 포지션 비중 × 가격 시나리오 수익률로 계좌 기여를 제시하고 비용을 구분한다. 시나리오 합계를 기대수익으로 부르지 않는다. 작은 기여만 남는다면 확대 가능성·다른 후보·교체를 검토한다.
- 실제 주문가능현금·보유 및 미체결·공식 종목 한도가 확인되면 총자산 미보고만으로 현금으로 마련할 수 있는 수량을 막지 않는다. 총자산·계좌 기여는 원 출처·시각을 밝히거나 미산정으로 둔다. 수량 산정에 필요한 현금·잔량·한도 정보가 부족하면 PRICE_ONLY로 가격표를 유지하고 수량·금액은 미산정이다. 공식 순위 미확인만으로 근거 있는 가격표까지 막지 않는다. 기존 보유는 실제 평균매입가와 별도 청산표로 표시한다.

## 4. 순위·회전율 진행도

- 내 수익률과 10위 수익률의 차이는 퍼센트포인트로, 현재 자산에서 해당 기준선까지 필요한 수익률은 `(1+10위수익률/100)/(1+내수익률/100)-1`로 구분한다.
- 위 계산은 현재 10위 성적이 변하지 않는다는 가정이다. 10위 성적을 최종 고정 커트라인이나 예상수익으로 쓰지 않는다. 수상권 진입 후에는 여유·기준선 변화·남은 기간을 보고 노출을 명시적으로 재검토한다.
- 최신 앱 회전율을 출발점으로 삼는다. 과거 거래가 있었다는 정정과 최신 성적을 유지하며 일부 잔고·일반 사전 산식으로 덮어쓰지 않는다.
- 매수·매도 각각 집계만으로 분모는 확정하지 않는다. 공식 산식은 확인 전 null이다. 남은 회전율은 퍼센트포인트로 표시하되 확정적인 잔여 거래대금에는 공식 근거가 필요하다. 5억/10억을 고정 추가 할당하지 않는다.
- 인정 종목 수·매매일수·남은 거래일·대회 최종 평가 시각도 따로 검토한다. 근거 없는 달력·일정·공식 성적은 만들지 않는다. 회전율만을 위한 상쇄·형식적 왕복·규정 우회를 하지 않는다.

## 5. 입력·점검·청산 일정

- 고정 1~3거래일 선호 없이 촉매·상품 구조·변동성·대회 종료·사용자 실행 가능성으로 최종 기한을 정한다. 당일 왕복은 의무가 아니며 기존 보유의 기한을 편의상 늘리지 않는다.
- 신규 입력 기본은 확인된 거래일 **09:00~14:30 전 중 한 번**, 잔량 취소·첫 점검은 **당일 15:00**, 실제 보유 점검·청산 창은 **15:00~15:15**다. 운영 기본값이지 거래소 규칙·매수 제한 시간이 아니다.
- 기본 창 이후 입력은 새 시각·가격 근거·실제 집행 가능성을 적은 명시적 새 버전에서만 정한다. 오늘 기존 마감·HLB 및 LS의 2026-10-02 15:10 KST 청산·사용자의 2026-10-06 일정은 자동 연장하지 않는다.
- 작성 시각·정보 기준·진입 시작·입력 마감·잔량 취소·첫 당일 점검·다음 점검·최종 청산을 절대 날짜·KST로 적는다. 충분한 시간에는 수시간 진입 창을 사용하고 5~10분짜리 창에는 구체적 사유를 쓴다.
- 실제 세션에서 작성 ≤ 진입 시작 < 입력 마감 ≤ 잔량 취소 < 최종 청산을 검증한다. 늦은 세션의 예외는 이유와 집행 가능 시간을 적는다. 매수 당일 첫 점검을 생략하지 않는다.
- 진입일에는 입력과 점검의 두 작업이 필요할 수 있다. 한 번의 클릭·전량 체결·취소 완료 시각을 보장하지 않는다. 입력 마감 후·다음 날 자동 재사용·GTC·소급 체결을 가정하지 않는다.

## 6. 주문과 평가 방식

`manual_on_observation`은 기존 수동 손절을 승계해 예약 점검 또는 사용자의 별도 실제 가격 관측에서 조건을 확인하면 청산을 안내한다. 정해진 점검 밖에 실제 확인된 손절도 유효하다. 앱 자동 감시·자동 주문·점검 사이 가격 경로의 확인을 뜻하지 않는다. 적용 시작·다음 점검·최종 기한을 새 버전으로 남긴다.

- `scheduled_review`는 계획한 시각의 실제 관측 가격으로 손절·시간 청산을 판단하고 시각을 기록한다. 익절 지정가의 실제 체결 상태와 구분한다. 점검 사이 통과는 자동 체결·소급 발동이 아니다.
- `verified_native_conditional`은 모의계좌 지원·관측일·감시 시간·만료·앱 종료·부분 체결·OCO/충돌을 검증한 경우만 쓴다. 일반 낮은 매도 지정가는 자동 손절이 아니며 매도 두 개는 OCO가 아니다.
- 입력 직전 손절 이하·익절 이상·알려진 가설 무효·거래 제한·중복 주문이면 신규 주문을 넣지 않는다. 일반 매수 지정가는 접수 후 급락·손절선 통과·새 악재로 자동 취소되지 않는다.
- 실제 무효 사유를 확인하면 미체결 취소부터 처리한다. 당일 점검에서 취소 완료·취소 중 추가 체결·부분 체결을 대사하고 실제 보유에 당일 청산 기준을 적용한다. 취소·최종 대사 뒤 같은 계획으로 새 매수를 추가하지 않는다. 이후 입력은 새 시각·가격·자금 근거가 있는 명시적 새 버전에서만 정한다.
- 손절·기한 조건이면 기존 익절 주문 취소 완료 후 실제 잔여수량 시장가 청산, 익절은 지정가로 처리한다. 익절 미체결 잔량의 처리 방식·시각도 사전에 적는다. 동시에 확인되면 손절 → 시간 청산 → 익절 순이다.
- 분할 익절은 새 계획에서 가격별 수량·총량·잔여수량·주문 충돌·취소 및 체결 대사를 명시할 수 있을 때만 허용한다. 고정 실행표로 발행하고 신규 매수의 모든 익절가가 진입가를 초과하는지 확인한다. 미검증 자동 트레일링을 가정하지 않는다.
- 점검 누락 시 다음 실제 확인에서 보유·미체결을 대사하기 전 신규 진입을 보류한다. 15:00/15:10 관측을 종가로 부르거나 실제 종가에 소급 체결시키지 않는다.
- 전량 청산하면 같은 계획은 종료한다. 새 근거를 검토한 별도 계획은 가능하지만 회전율만을 위한 재진입은 하지 않는다.

## 7. 발행·변경·보관

`docs/record-publication.md`의 판단 전달 우선·간결한 기록 방식을 적용한다. 판단이 끝나면 기록·검사·Git 작업 전에 짧은 진행 메시지로 행동·가격·수량·유효시간·핵심 근거를 먼저 전달한다. 판단에 영향을 주는 새 사실·가격 유효성 문제·계산 오류가 없으면 이후 추가 조사·재계산을 하지 않는다. 신규·수정 계획의 필수 정보는 한 번 상세히 남기고, 반복 회차는 계획 ID/버전·새 관측과 변경·다음 행동만 짧게 기록한다. 모든 후보와 과거 계획을 매번 복제하지 않는다.

기존 발동 청산 → 계획 ID·버전·상태·기준 시각 → 가격·수량별 확정 실행표 → 순위 격차·계좌 기여·자격 진행 → 근거·비용 전 지표·출처 순으로 제공한다. 반복 요청을 새 장중 확인 조건으로 바꾸지 않는다.

새 정책·보고·문서 만료만으로 기존 주문이 바뀌지 않는다. 재산정·오류 정정·교체·수량·일정 변경은 사유·총수량·이전 버전 대체 관계를 명시하고 원본을 보존한다. 실제 취소·매도 전 자금·수량을 재사용하지 않는다.

모의투자 계좌·성적·보유·주문·계획·일지는 사용자 승인에 따라 공개 data/account.json과 data/days/YYYY-MM-DD.md에 저장하고 GitHub에 동기화한다. 계좌번호·성명·인증정보·원본 첨부·로컬 사용자 경로는 제외한다. 기존 기록과 출처·관측 시각은 보존한다. 실제 하지 않은 커밋·저장·주문·취소·알림을 완료했다고 쓰지 않는다. 순위가 상승했다고 새 근거 없이 기존 익절을 없애거나 손절을 늦추지 않는다.
