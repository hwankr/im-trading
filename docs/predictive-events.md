# 발표 전 예측 매매 · 정시 확인형

운영 정책 추가일: 2026-09-11. 모의투자 계획 지침이며 대회 규정·실행 프로그램·실제 주문 기록이 아니다.

## 목적

수익 기회를 검토하기 위해 CPI·금리 결정·기업 실적·수주 등 공개자료에 근거한 발표 전 진입을 허용한다.
이벤트가 예정되어 있다는 사실만으로 전액 현금 또는 일괄 진입 금지를 선택하지 않는다.
반대로 대회·모의투자라는 이유만으로 근거 없는 방향성 베팅이나 거래 강제를 하지 않는다.
핵심은 발표 수치 자체를 맞히는 것만이 아니라 **시장 예상과의 차이, 가격 반영, 실제 보유기간의 손익 구조**다.
예측을 허용하는 정책 변경은 특정 종목의 매수 승인이나 기존 HOLD 계획의 자동 취소가 아니다.

## 1. 실행 방식

현재 사용자 확인을 받은 신규 계획 기본값은 `config/planning.json`의 `confirmed_execution`을 따른다.
거래일 15:00에 실제 가격을 확인하고 15:00~15:15 KST에 필요한 수동 주문·미체결 정리를 모은다.
동일한 시간대와 지연 손절·갭 위험의 수용을 매번 다시 묻지 않는다. 시간대 변경·실행 불가 등 새로운 사실이 있으면 다시 확인한다.
일반 안내의 예시 시간대와 달리 확정된 기본값이지만, 개별 계획에는 실제 거래일과 절대 확인·청산 시각이 필요하다.
자동 예약·상시 감시·자동 주문·자동 알림은 없고, 새로운 분석은 사용자 요청이 있을 때만 한다.

정시 사이 손절가 통과는 자동 손절이 아니다. 평가 시각에 확인된 유효 손절 사유는 이후 반등을 이유로 지우지 않는다.
야간 이벤트를 국내장에서 미리 매수하면 다음 날 시초가뿐 아니라 **다음 실제 확인·매도 시점까지**의 위험을 평가한다.
야간 미국시장이나 다음 날 시초가에 사용자가 팔 수 있다고 가정하여 손익을 산출하지 않는다.
확인을 놓치면 다음 실제 확인 때 보유·미체결부터 대사하고 신규 진입은 그 전에 보류한다.

## 2. 예측 근거표

발표 전 다음 항목을 기록한다. 확인 사실과 AI의 판단을 별도 칸에 둔다.

| 항목 | 필수 내용 |
| --- | --- |
| 이벤트 | 명칭, 대상 월/분기, 공식 발표 날짜·원 시간대·KST, 국내 실행 가능 시간 |
| 정보 시점 | 판단 시각 이전에 실제 공개된 자료만 사용. 발표 후 결과·개정값 소급 사용 금지 |
| 시장 예상 | 동일 항목·전월비/전년비·계절조정 기준의 컨센서스, 출처·관측 시각. 기관 단일 전망과 구분 |
| 참고 모델 | 기관 나우캐스트 등의 값과 갱신일. 공공 모델을 자체 모델 또는 미공개 정보로 표시하지 않음 |
| AI 기본 전망 | 예상 수치 또는 방향, 선택 이유, 반대 근거, 신뢰 수준 |
| 기대 차이 | 시장 예상보다 높음/낮음/유사함과 그 차이가 의미 있다고 판단하는 이유 |
| 가격 반영 | 관련 주가·금리·환율의 관측값과 시각. 컨센서스를 실제 포지셔닝의 완전한 증거로 사용하지 않음 |
| 종목 연결 | 해당 결과가 선택한 종목의 손익에 전달되는 경로와 그 경로가 실패할 수 있는 이유 |
| 결론 | 선제 진입 / 다른 기회 선택 / HOLD / BLOCKED 중 하나와 결정 이유 |

CPI와 근원 CPI, PPI와 CPI, 전월비와 전년비를 섞지 않는다. 발표 대상 기간 이후의 유가 변동을 과거 월 CPI의 직접 측정치로 넣지 않는다.
공개 나우캐스트가 컨센서스와 유사하면 그 사실만으로 독자적인 정보 우위를 주장하지 않는다.
시장 예상이 틀릴 수 있듯 AI 전망도 틀릴 수 있다. ‘가능하다’만 반복하지 말고 근거가 있는 기본 전망을 하나 제시한다.
자료가 불충분하면 미확인을 표시한다. 실제 숫자·호가·일정·제한은 예측 대상으로 대신 채우지 않는다.

## 3. 시나리오와 기대 손익

기본·유리·불리한 경우를 내부적으로 비교하되, 최종 주문은 종목별 진입가·익절가·손절 기준가 각각 하나로 단순화한다.
복수 시나리오를 사용자에게 떠넘겨 장중 대응을 반복하도록 만들지 않는다.

확률을 쓰면 `probability_type`을 실증 추정/모델 추정/주관적 판단 중 구분하고 근거·표본·오차를 명시한다.
근거 없이 승률 60% 또는 70%를 확정하지 않는다. 방어 가능한 수치 확률이 없으면 null로 두고 질적 비교만 한다.
주관적 확률의 합은 100%여야 하며 작은 확률 수정에도 기대값이 바뀌는지 검토한다.

수치가 뒷받침되면 기대손익 = 각 시나리오 확률 × 다음 실제 실행 시점 기준 손익의 합 - 예상 비용으로 검토한다.
확률·손익 가정이 근거 없으면 정밀한 기대값을 만들어 매수를 정당화하지 않는다.
예측 적중률, 주가 방향 적중률, 실제 체결 후 비용 차감 수익률은 별개다.
예상보다 낮은 CPI가 반드시 주가 상승으로 이어지거나 높은 CPI가 반드시 주가 하락으로 이어진다고 단정하지 않는다.

## 4. 투입 규모

아래 비중은 검증된 최적해나 대회 규칙이 아니라 새 운영을 시작하기 위한 위험 한도다. 목표 투입액이나 의무 매수가 아니다.
기준은 최신 확인된 계좌 자산이며 증거금 배수의 최대주문가능금액이 아니다. 현금 매수와 공식 편입 제한을 동시에 지킨다.

- 단일 선제 이벤트의 최초 편입: 계좌 자산의 최대 10%.
- 같은 이벤트에 함께 노출되는 모든 종목 합계: 최대 20%. 강한 근거와 새 계획 검토가 있어야 하며 자동 증액하지 않는다.
- 일반 보유까지 합친 시작 단계 전체 편입 상한: 40%. 이벤트 한도는 이 상한에 추가하는 별도 자금이 아니다.
- 진입가와 손절 기준가의 차이로 계산한 단일 거래 손절 위험 예산: 계좌의 0.5% 이내, 비용 여유 별도.
- 같은 이벤트에 대한 불리한 스트레스 시나리오 손실 예산: 계좌의 1% 이내를 목표로 수량 축소.

수량은 현금·노출 비중·계산상 손절 예산·스트레스 예산이 허용하는 수량 중 작은 값을 정수로 내림한다.
스트레스 하락률은 관측 변동성과 유사 이벤트 등을 근거로 정하고, 수량을 늘리려고 임의로 낮추지 않는다.
손절 예산과 스트레스 예산 모두 보장 손실 상한이 아니다. 갭·유동성·체결 지연·더 극단적인 결과로 초과할 수 있다.
종목 이름이 달라도 같은 CPI나 금리 방향에 의존하면 공통 노출로 합산한다.
확신 표현만으로 레버리지·물타기·대회 제한 우회를 허용하지 않는다. 선제 이벤트 전략에서는 레버리지 상품을 기본에서 제외한다.

## 5. 발행과 평가

실행 가능한 계획에는 가격·수량·기한과 함께 이벤트, 시장 예상, AI 기본 전망, 반대 근거, 다음 실제 확인 시점을 짧게 붙인다.
실행 조건은 원래 고정 가격·정시 평가 방식에 따르며, 발표 직후 다시 접속하거나 장중 호가를 계속 확인하라고 요구하지 않는다.
발표 결과에 따라 별도의 기본 가설 청산 조건을 추가하려면 진입 전에 구체화해야 한다. 기존 청산 조건을 사후 확대·완화하지 않는다.
이미 발동한 기존 손절·시간 청산이 새 예측보다 우선한다. 운영 선호 변경으로 과거 거래를 다시 살리지 않는다.

발표 후 사용자 요청이 있으면 원래 예측·정보 시점·실제 결과·시장 반응·비용 차감 거래 결과를 구분해 평가한다.
손실 사례와 비매매 사례도 보존하고 맞은 사례만 골라 성과를 주장하지 않는다.
실제 개인 예측 기록·계좌·주문은 비공개 `data/` 또는 대화에만 남긴다. 공개 저장소에는 일반 지침과 빈 양식만 둔다.
