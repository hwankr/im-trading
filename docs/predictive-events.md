# 발표 전 예측 매매 · 유연한 진입과 정시 점검

운영 정책 추가일: 2026-09-11. 진입 시간 분리: 2026-09-14. 공격형 위험 예산 변경: 2026-09-15.
모의투자 계획 지침이며 대회 규정·실행 프로그램·실제 주문 기록이 아니다.

## 목적

CPI·금리 결정·기업 실적·수주 등 공개자료에 근거한 발표 전 진입을 허용한다.
이벤트 존재만으로 전액 현금·일괄 진입 금지를 선택하지 않는다. 반대로 대회·모의투자라는 이유로 근거 없는 거래를 강제하지 않는다.
핵심은 수치 자체의 적중뿐 아니라 **시장 예상과의 차이, 가격 반영, 실제 보유기간의 손익 구조**다.
정책 변경은 특정 종목의 매수 승인이나 기존 계획의 자동 변경이 아니다.

## 1. 실행 방식

`config/planning.json`의 유연한 `entry`와 `confirmed_execution`을 구분해서 사용한다.
신규 매수는 15시에만 입력하지 않는다. 기본은 확인된 거래일 09:00~14:30 전 중 편한 때 한 번 입력하고 15:00에 미체결을 취소·확인한다.
15:00~15:15는 보유·미체결 점검·필요 청산의 기본 시간이다. 분석·매수·점검을 한 시간대에 강제로 묶지 않는다.
실제 날짜·시각은 개별 계획에 적고, 이벤트 전에 충분한 주문 유효시간을 주되 발표 이후로 선제 매수 계획을 그대로 넘기지 않는다.
장중 발표 등으로 짧은 유효시간이 필요한 경우 이유를 적는다. 상시 감시를 전제로 한 주문은 기본에서 제외한다.

이미 확인된 점검 시간과 지연 대응·갭 위험 수용은 재사용한다. 새 실행 충돌·시간 변경에 필요한 사실만 다시 확인한다.
매수일은 입력 작업과 그날 첫 점검 작업이 필요하다. 매수 없는 보유일은 한 차례 점검을 기본으로 한다.
넓은 시간 동안 대기하는 일반 지정가는 가설 훼손·급락·손절선 통과로 자동 취소되지 않으며 확인 전 불리하게 체결될 수 있다.
입력 전 무효 사유를 확인하고, 접수 후 사유를 실제 확인했으면 잔량 취소를 우선한다. 취소 중 추가 체결도 대사한다.

위험은 가능한 최초 체결부터 **다음 실제 점검·매도 시점까지** 평가한다. 이른 진입이면 매수 당일 위험도 포함한다.
야간 발표 직후나 다음 날 시초가에 사용자가 대응할 수 있다고 가정하지 않는다.
정시 사이 가격 통과는 자동 손절이 아니다. 실제 확인한 유효 청산 사유는 반등을 이유로 지우지 않는다.
점검을 놓치면 다음 실제 확인 때 보유·미체결부터 대사하고 그 전 신규 진입을 보류한다.
자동 예약·상시 감시·자동 주문·알림은 없고 새로운 분석은 사용자 요청 시에만 한다.

## 2. 예측 근거표

발표 전 공개된 자료만 사용하고 확인 사실·시장 예상·참고 모델·AI 판단을 분리한다.

| 항목 | 필수 내용 |
| --- | --- |
| 이벤트 | 명칭·대상 기간·공식 발표 날짜·원 시간대·KST·국내 실행 가능 시간 |
| 정보 시점 | 판단 시점 이전 공개 자료. 발표 결과·개정값의 소급 사용 금지 |
| 시장 예상 | 같은 항목·전월비/전년비·계절조정 기준의 컨센서스, 출처·관측 시각. 단일 기관 전망과 구분 |
| 참고 모델 | 기관 나우캐스트·갱신일. 공개 모델을 자체 모델·미공개 정보로 표시하지 않음 |
| AI 기본 전망 | 예상 수치 또는 방향, 선택 이유·반대 근거·신뢰 수준 |
| 기대 차이 | 시장 예상보다 높음/낮음/유사함과 의미 있다고 판단하는 이유 |
| 가격 반영 | 관련 주가·금리·환율 관측값·시각. 컨센서스를 실제 포지셔닝의 완전한 증거로 취급하지 않음 |
| 종목 연결 | 보유 종목 손익에 전달되는 경로와 실패할 수 있는 이유 |
| 결론 | 선제 진입 / 다른 기회 / HOLD / BLOCKED 중 하나와 근거 |

CPI·근원 CPI·PPI, 전월비·전년비를 섞지 않는다. 대상 기간 이후 유가 변동을 과거 월 CPI의 직접 측정치로 쓰지 않는다.
나우캐스트가 컨센서스와 비슷하다는 사실만으로 독자적인 정보 우위를 주장하지 않는다.
기본 전망 하나를 제시하되 틀릴 수 있음을 인정한다. 실제 숫자·호가·일정·거래 제한의 미확인을 예측으로 대신하지 않는다.

## 3. 시나리오와 기대 손익

기본·유리·불리한 경우를 비교하되 최종 주문은 진입·익절·손절 각 하나로 확정한다. 장중 여러 갈래 대응을 사용자에게 떠넘기지 않는다.
가격 설정에는 시장 예상 차이와 함께 실행 가능성을 검토한다. 깊은 눌림 가격만 고집하거나 늦었다는 이유로 무조건 추격하지 않는다.
확인된 호가에서 비용·위험이 허용되면 체결을 우선하는 지정가를 선택할 수 있으나 전량 체결을 보장하지 않는다.

확률을 쓰면 실증/모델/주관적 판단을 구분하고 근거·표본·오차를 명시한다. 근거 없는 승률 60%·70%는 쓰지 않는다.
방어 가능한 수치 확률이 없으면 null이다. 주관적 확률의 합은 100%이며 작은 확률 변경에 대한 기대값 민감도를 검토한다.
근거가 있으면 기대손익 = 시나리오별 확률 × 다음 실제 실행 시점 손익의 합 - 예상 비용으로 검토한다.
근거 없는 정밀한 기대값으로 매수를 정당화하지 않는다. 지표 적중·주가 방향 적중·비용 차감 거래성과는 별개다.
예상보다 낮은 CPI가 반드시 주가 상승, 높은 CPI가 반드시 하락으로 이어진다고 단정하지 않는다.

## 4. 투입 규모 — 2026-09-15 변경

수익 기회와 수상 거래 요건을 함께 고려한 사용자의 공격성 확대 요청을 반영한다.
다음은 운영 한도이지 대회 규칙·검증된 최적해·의무 투입액이 아니다. 기준은 최신 확인 계좌 자산이며 증거금 배수의 주문가능금액이 아니다.
이전 10%·20%·40% 소액 탐색 한도 대신 `config/planning.json`의 현재 `risk_policy`를 적용한다.

- 일반 보유 포함 전체 편입: 최대 75%, 신규 매수 후 현금 여유 최소 25%, 최대 동시 보유 3종목.
- 단일 종목 최대 30%. 통상 25% 규모를 검토하되 다른 위험 한도가 더 작으면 수량을 줄인다.
- 선제 이벤트 최초 편입: 계좌 최대 25%.
- 같은 이벤트 전체 노출: 최대 40%. 강한 근거와 새 계획 검토 없이는 자동 증액하지 않는다. 전체 75% 안에 포함된다.
- 한 거래의 진입가·손절가 차이로 계산한 손절 위험: 계좌 1% 이내. 전체 보유·미체결 합산 계획 손절 위험은 3% 이내. 비용 여유를 남긴다.
- 같은 이벤트의 불리한 스트레스 손실 예산: 계좌 2.5% 이내를 목표로 수량 조절.
- 공격형 적용 시작 시 확인 자산 대비 5% 감소를 실제 계좌 점검에서 확인하면 신규 진입을 중단하고 재검토한다.
  기준점은 비공개로 기록하고 입출금을 조정한다. 손실 뒤 자동 초기화하지 않는다. 기존 청산 조건은 유지하며 자동 감시나 손실 보장은 아니다.

현금·노출·손절·스트레스 한도가 허용하는 수량 중 작은 값을 정수로 내림한다. 미체결 매수도 전량 체결될 수 있다고 계산한다.
스트레스 하락률은 관측 변동성·유사 이벤트로 설명하고 수량을 늘리려고 임의로 낮추지 않는다.
한도는 보장 손실 상한이 아니다. 갭·유동성·체결 지연·극단적 결과·대기 주문의 불리한 체결로 초과할 수 있다.
종목이 달라도 같은 CPI·금리·업종 방향에 의존하면 합산한다. 선제 이벤트에 레버리지 상품을 기본 사용하지 않는다.
이번 변경은 더 큰 금액의 손익을 수용하는 운영 변경이지 예측의 질·승률·손익비가 개선됐다는 주장이 아니다.
기존 가격·기간을 유지하며 수량만 바꿀 때에도 새 버전, 총수량, 기존 주문 취소와 중복 방지를 명시한다.
진입 시간 확대 또는 거래 부족만으로 이후 위험 한도·손절폭·보유기한을 다시 확대하지 않는다.

## 5. 발행과 평가

가격·수량·기한, 넓은 입력 가능 시간과 취소 시각, 첫 당일 점검·다음 점검을 명시한다.
시장 예상·AI 전망·반대 근거를 짧게 붙인다. 발표 직후 다시 접속하거나 호가를 계속 보라고 요구하지 않는다.
발표 결과에 따른 별도 가설 청산 조건은 진입 전 구체화한다. 기존 청산 조건을 사후 확대·완화하지 않는다.
이미 발동한 손절·시간 청산이 새 예측보다 우선한다.

새 계획에서는 공식 회전율·인정 종목 수·거래일수와 남은 일정을 수익 기회와 함께 검토한다. 실제 앱 값과 시각을 우선한다.
회전율 산식이 미확인이면 500%를 거래대금 5억 원으로 확정하지 않는다. 조건부 산술 예시·계획·실제 성과를 구분한다.
공식 요건 충족 여부를 추측하지 않으며, 부족분을 채우기 위한 아무 종목 매수·불필요한 상쇄 거래·규칙 우회를 하지 않는다.

발표 후 요청이 있으면 원래 예측·정보 시점·실제 지표·시장 반응·비용 차감 거래 결과를 분리해 평가한다.
실패·비매매 사례도 보존하며 맞은 사례만 골라 성과를 주장하지 않는다.
개인 예측·계좌·주문 기록은 비공개 `data/` 또는 대화에만 남기고 공개 저장소에는 일반 지침·빈 양식만 둔다.
