# 발표 전 예측 매매 · 수상 기여와 유연한 진입

정책 추가: 2026-09-11. 진입 시간 분리: 2026-09-14. 현행 목표·위험 예산: 2026-09-16.
모의투자 전용이며 목표는 최종 10위 이내 수상이다. 현재 한도는 `config/planning.json`, 전체 판단 기준은 `docs/tournament-strategy.md`를 따른다. 이전 이벤트 소액 한도는 현행 기준이 아니다.

## 1. 이벤트를 관망의 자동 사유로 쓰지 않는다

CPI·금리 결정·기업 실적·수주 등 공개자료에 근거한 발표 전 진입을 허용한다. 시장 예상과의 차이, 가격 반영, 다음 실제 청산 가능 시점까지의 손익 구조를 비교한다. 발표가 있다는 이유만으로 전액 현금·일괄 매수 금지를 선택하지 않는다.

수익 기여가 충분한 주도주·업종·기업 촉매를 기존 보유와 함께 비교한다. 한 종목 보유 중이라는 이유로 다른 기회를 닫지 않는다. 인버스는 하락 가설의 수익 기여가 대안보다 낫다고 판단할 때 선택하며 방어용 기본값이 아니다.

수상 목표가 확인되지 않은 가격·정보·확률로 거래를 강제하라는 뜻은 아니다. 확인 사실, 시장 예상, 참고 모델, AI 전망을 구분한다. 새 정책은 기존 주문 수량·손절·기한을 자동 변경하지 않는다.

## 2. 근거표

발표 전에 공개된 자료만 사용한다. 공식 일정은 원 시간대와 KST, 발표 후 국내 실행 가능 시각까지 확인한다.

| 항목 | 필수 내용 |
| --- | --- |
| 이벤트 | 명칭·대상 기간·공식 발표 시각·시간대 |
| 정보 기준 | 판단 시점 이전 자료, 사후 결과·개정값 소급 사용 금지 |
| 시장 예상 | 같은 항목·전월비/전년비·계절조정 기준의 컨센서스와 출처·시각 |
| 참고 모델 | 기관·갱신일, 공개 나우캐스트를 독자적 정보로 부르지 않음 |
| AI 전망 | 기본 방향·시장 예상과의 차이·이유·반대 근거·불확실성 |
| 가격 반영 | 관련 주가·금리·환율과 실제 관측 시각, 과거 가격과 현재 호가 구분 |
| 전달 경로 | 이벤트가 해당 종목과 계좌 손익에 연결되는 경로와 실패 시나리오 |
| 기회 비교 | 기존 보유·다른 후보·현금과 비교한 비용 후 수익 기여 |
| 결론 | 선제 진입 / 다른 기회 / HOLD / 후보별 BLOCKED |

CPI·근원 CPI·PPI, 전월비·전년비를 혼동하지 않는다. 대상 기간 이후 유가 움직임을 과거 CPI의 직접 측정치로 쓰지 않는다. 단일 기관 예측을 컨센서스로 부르거나 나우캐스트와 컨센서스가 같다는 이유로 예측 우위를 주장하지 않는다.

## 3. 가격·시나리오

기본·유리·불리한 경우를 비교하되 최종 주문은 진입·익절·손절 각 하나로 확정한다. 장중 여러 조건·반복 정정·VWAP·몇 분 뒤 확인을 추가로 떠넘기지 않는다.

깊은 눌림만 기다리지 않는다. 실제 확인 호가, 변동성, 스프레드·유동성, 비용 후 손익이 맞으면 체결 우선 지정가도 선택한다. 미확인 호가의 즉시 체결이나 특정 승률을 보장하지 않는다. 대회에 필요한 수익률을 역산해 근거 없는 익절가를 만들지 않는다.

확률을 쓸 때는 실증·모델·주관 판단을 구분하고 근거·오차·민감도를 밝힌다. 방어 가능한 수치가 없으면 null이다. 확률 합계는 100%이고 작은 확률 변화에도 기대값이 뒤집히는지 확인한다. 근거가 있을 때만 시나리오별 확률 가중 손익에서 비용을 차감해 기대손익을 계산한다.

포지션의 계좌 기여는 비중 × 시나리오 수익률로 설명한다. 이것은 예상수익·승리 확률이 아니다. 지표 적중, 주가 방향 적중, 실제 비용 차감 성과는 서로 다르다.

## 4. 현행 수량 산정

- 전체 편입 최대 90%, 현금 최소 10%, 동시 보유 최대 3종목, 단일 종목 최대 45%. 기회가 충분할 때 전체 70~90%, 핵심 35~45%, 보조 20~30%를 검토한다.
- 발표 전 최초 편입 최대 40%, 같은 이벤트 합산 최대 70%. 전체 90% 한도 안에 포함한다.
- 한 거래 계획 손절 손실 예산 계좌 2%, 전체 보유·매수 미체결 합산 5%, 동일 이벤트 스트레스 손실 예산 5% 이내로 검토한다. 비용·체결 여유를 남긴다.
- 프로필 시작 확인 자산보다 10% 감소를 실제 확인하면 신규 진입을 멈추고 가설·남은 기간·집행을 재평가한다. 자동 영구 중단이 아니며 재개는 명시적 새 계획으로 결정한다. 기존 청산은 유지하고 기준점은 손실 뒤 초기화하지 않는다.

이 숫자는 운영 예산이지 공식 규칙·검증된 최적해·보장 손실 상한이 아니다. 공식 원금 기준 단일 종목 제한을 별도로 적용하고, 현금·운영 비중·공식 비중·손절·스트레스 중 허용 수량이 가장 작은 값을 내림한다. 미체결 매수도 전량 체결 가능성을 반영한다.

같은 금리·물가·시장·업종에 의존하는 포지션은 합산한다. 서로 반대되는 포지션을 거래대금만 늘리려고 동시에 추가하지 않는다. 선제 이벤트에 레버리지를 기본 사용하지 않으며, 규정상 허용 여부와 상품 구조를 따로 검증한다.

스트레스 변동률은 관측 변동성·유사 이벤트·보유기간으로 설명한다. 큰 수량을 만들려고 임의로 낮추지 않는다. 갭·유동성·극단적 결과·확인 지연·대기 주문의 불리한 체결로 실제 손실은 예산을 넘을 수 있다. 큰 비중이 예측력·승률을 개선하는 것은 아니다.

## 5. 실제 실행 가능 시각까지 위험을 본다

위험 구간은 가능한 최초 체결부터 다음 실제 점검·매도까지다. 야간 발표 직후나 다음 날 시초가에 사용자가 대응할 수 있다고 가정하지 않는다. 매수 당일 위험과 첫 점검을 포함한다.

신규 입력 기본은 확인된 거래일 09:00~14:30 전 중 한 번, 당일 15:00 미체결 취소·대사, 15:00~15:15 보유 점검·청산이다. 분석과 매수·점검은 분리한다. 날짜·KST를 명시하고 충분한 진입 창을 확보하되 발표 이후로 선제 매수 계획을 자동 넘기지 않는다.

일반 지정가는 가설 훼손·급락·손절선 통과로 자동 취소되지 않는다. 입력 전에 무효 사유를 확인하고 접수 후 실제 확인하면 잔량 취소부터 처리한다. 취소 중 추가 체결도 대사한다. 매수 당일 첫 점검을 생략하지 않고 점검을 놓치면 다음 실제 대사 전에 신규 진입을 보류한다.

정시 손절과 익절 지정가를 구분한다. 일반 낮은 매도 지정가는 자동 손절이 아니며 OCO를 가정하지 않는다. 실제 확인한 유효 청산 사유를 반등·수상 목표로 지우지 않는다. 앱 지원을 검증하지 않은 조건 주문·자동 승계를 가정하지 않는다.

## 6. 발행·교체·평가

가격·수량·기한·입력 구간·취소·첫 당일 점검·다음 점검을 명시한다. 통상 1~3거래일을 검토하되 촉매·상품 구조·일정에 맞춰 정확한 기한을 정한다. 입력 시간을 넓힌다는 이유로 기존 손절·기한을 늘리지 않는다.

최신 사용자 보고 또는 직접 확인한 앱의 내 성적·순위·10위 성적·공식 회전율·종목 수·매매일수와 관측일을 재사용한다. 현재 10위 성적을 최종 커트라인으로 확정하지 않는다. 과거 매매가 있었다는 정정을 반영하고 일부 잔고로 회전율을 0으로 초기화하지 않는다. 공식 산식 미확인 시 잔여 거래대금을 단정하지 않는다.

기존 보유 촉매가 약해지거나 더 나은 기회가 확인되면 본전까지 기다리지 않는 교체도 검토한다. 이미 발동한 손절·시간 청산은 먼저 처리하고 새 버전에서 총수량·기존 주문 취소·실제 매도·신규 자금 사용을 구분한다. 체결 확인 전 매도대금을 재사용하지 않는다.

발표 후 요청에서는 원래 전망·정보 시점·실제 지표·시장 반응·비용 차감 성과를 분리해 평가한다. 실패·비매매 사례도 보존한다. 모의투자 계좌·성적·보유·주문·계획·일지는 사용자 승인에 따라 공개 data/account.json과 data/days/YYYY-MM-DD.md에 저장하고 GitHub에 동기화한다. 계좌번호·성명·인증정보·원본 첨부·로컬 사용자 경로는 제외한다. 기존 기록과 출처·관측 시각은 보존한다. 자동 감시·주문·알림을 실행하는 문서가 아니다.
