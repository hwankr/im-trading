## 1. 이벤트를 관망의 자동 사유로 쓰지 않는다

CPI·금리 결정·기업 실적·수주 등 공개자료에 근거한 발표 전 진입을 허용한다. 시장 예상과의 차이, 가격 반영, 다음 실제 청산 가능 시점까지의 손익 구조를 비교한다. 발표가 있다는 이유만으로 전액 현금·일괄 매수 금지를 선택하지 않는다.

수익 기여가 충분한 주도주·업종·기업 촉매를 기존 보유와 함께 비교한다. 한 종목 보유 중이라는 이유로 다른 기회를 닫지 않는다. 인버스는 하락 가설의 수익 기여가 대안보다 낫다고 판단할 때 선택하며 방어용 기본값이 아니다.

수상 목표가 확인되지 않은 가격·정보·확률로 거래를 강제하라는 뜻은 아니다. 확인 사실, 시장 예상, 참고 모델, AI 전망을 구분한다. 새 정책은 기존 주문 수량·손절·기한을 자동 변경하지 않는다.

## 3. 가격·시나리오

기본·유리·불리한 경우를 비교하되 진입 상한·손절은 각 하나, 익절은 확정 실행표로 정한다. 새 계획에서 분할 익절을 사용할 때만 가격별 수량·총량·잔여수량 및 주문 충돌·취소·체결 대사를 명시하고, 신규 매수의 모든 익절가는 진입가 초과를 검증한다. 미검증 자동 트레일링·장중 여러 조건·반복 정정·VWAP·몇 분 뒤 확인을 추가로 떠넘기지 않는다.

깊은 눌림만 기다리지 않는다. 실제 확인 호가, 변동성, 스프레드·유동성, 비용 후 손익이 맞으면 체결 우선 지정가도 선택한다. 미확인 호가의 즉시 체결이나 특정 승률을 보장하지 않는다. 대회에 필요한 수익률을 역산해 근거 없는 익절가를 만들지 않는다.

확률을 쓸 때는 실증·모델·주관 판단을 구분하고 근거·오차·민감도를 밝힌다. 방어 가능한 수치가 없으면 null이다. 확률 합계는 100%이고 작은 확률 변화에도 기대값이 뒤집히는지 확인한다. 근거가 있을 때만 시나리오별 확률 가중 손익에서 비용을 차감해 기대손익을 계산한다.

포지션의 계좌 기여는 비중 × 시나리오 수익률로 설명한다. 이것은 예상수익·승리 확률이 아니다. 지표 적중, 주가 방향 적중, 실제 비용 차감 성과는 서로 다르다.

손익비는 계산·비교하되 단독 탈락 기준으로 쓰지 않는다. 낮은 손익비·불명확한 확률도 촉매·가격·비용·실패 시나리오와 함께 설명하고, 유리한 판단을 만들기 위해 무시하거나 수치를 조작하지 않는다. 총자산·계좌 기여는 원 출처와 관측 시각을 밝히고, 미확인이면 미산정으로 남긴다.

## 4. 현행 수량 산정

- 공식 원금의 50%(원금 1억원 기준 5천만원) 단일 종목 한도를 적용한다. 후보·보유 종목 수와 이벤트 비중에 운영상 고정 상한을 두지 않고, 촉매·비용 후 기여·자금 교체·공통 위험을 비교해 수량을 정한다.
- 실제 주문가능현금으로만 매수(cash-only)하며, 보유·매수 미체결 전량 체결 가능성·비용 및 체결 여유를 반영한다. 취소 완료·취소 중 체결 대사·실제 매도·주문가능현금 확인 전 같은 자금을 재사용하지 않는다.
- 실제 주문가능현금·보유 및 미체결·공식 종목 한도가 확인되면 총자산 미보고만으로 현금으로 마련할 수 있는 수량을 막지 않는다. 비용 여유는 고정 10만원 대신 실제 거래비용과 체결 여유의 근거로 정한다.
- 계획 손절액과 전체 보유·매수 미체결의 합산 계획 손절액, 동일 이벤트 스트레스 손실을 참고 수치로 계산·기록한다. 신규·명시적 버전 수정 계획에서 폐지한 비중·손절 예산·스트레스 손실 상한은 수량 제한·진입 차단 조건으로 사용하지 않는다.
- 기준자산과 실제 자산 감소는 출처·시각·감소폭을 보고·기록하고 가설·남은 기간·집행을 분석한다. 감소율만으로 신규 진입·분석을 자동 중지하거나 일시중지하지 않는다. 손실 뒤 기준점이나 기존 발동 청산을 지우지 않는다.

실제 주문가능현금·비용 및 체결 여유·공식 원금 기준 단일 종목 한도가 허용하는 정수 수량을 내림하고, 보유와 매수 미체결 전량 체결 가능성을 함께 반영한다. 동일 이벤트 노출은 참고 위험으로 계속 합산하며 독립 위험으로 취급하지 않는다.

같은 금리·물가·시장·업종에 의존하는 포지션은 합산한다. 서로 반대되는 포지션을 거래대금만 늘리려고 동시에 추가하지 않는다. 선제 이벤트에 레버리지를 기본 사용하지 않으며, 규정상 허용 여부와 상품 구조를 따로 검증한다.

스트레스 변동률은 관측 변동성·유사 이벤트·보유기간으로 설명한다. 큰 수량을 만들려고 임의로 낮추지 않는다. 갭·유동성·극단적 결과·확인 지연·대기 주문의 불리한 체결로 실제 손실은 계획 손절액과 참고 시나리오보다 커질 수 있다. 큰 비중이 예측력·승률을 개선하는 것은 아니다.

## 5. 실제 실행 가능 시각까지 위험을 본다

위험 구간은 가능한 최초 체결부터 다음 실제 점검·매도까지다. 야간 발표 직후나 다음 날 시초가에 사용자가 대응할 수 있다고 가정하지 않는다. 매수 당일 위험과 첫 점검을 포함한다.

신규 계획의 입력 기본은 확인된 거래일 09:00~14:30 전 중 한 번, 당일 15:00 미체결 취소·대사, 15:00~15:15 보유 점검·청산이며 공식 일률 상한은 아니다. 이후 입력은 새 시각·가격 근거·실제 집행 가능성을 적은 명시적 새 버전에서만 정한다. 기존 오늘 마감·청산이나 사용자의 2026-10-06 일정, 발표 전 계획을 자동 연장·승계하지 않는다. 분석과 매수·점검은 분리하고 절대 날짜·KST를 명시한다.

일반 지정가는 가설 훼손·급락·손절선 통과로 자동 취소되지 않는다. 입력 전에 무효 사유를 확인하고 접수 후 실제 확인하면 잔량 취소부터 처리한다. 취소 중 추가 체결도 대사한다. 매수 당일 첫 점검을 생략하지 않고 점검을 놓치면 다음 실제 대사 전에 신규 진입을 보류한다.

정시 손절과 익절 지정가를 구분한다. 일반 낮은 매도 지정가는 자동 손절이 아니며 OCO를 가정하지 않는다. 실제 확인한 유효 청산 사유를 반등·수상 목표로 지우지 않는다. 앱 지원을 검증하지 않은 조건 주문·자동 승계를 가정하지 않는다.

가격·수량·기한·입력 구간·취소·첫 당일 점검·다음 점검을 명시한다. 고정 1~3거래일 선호 없이 촉매·상품 구조·대회 종료·사용자 실행 가능성으로 정확한 기한을 정한다. 입력 시간을 넓힌다는 이유로 기존 손절·기한을 늘리지 않는다.
