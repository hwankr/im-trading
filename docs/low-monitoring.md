# 장중 확인을 줄이는 운영

최초 변경일: 2026-09-11. 진입 시간 분리: 2026-09-14. 대회 규정이 아니라 사용자 요청에 맞춘 계획 작성 정책이다.
목표는 **장중 반복 확인·정정·재진입 부담은 줄이되, 짧은 입력 시간 때문에 실행 기회를 불필요하게 줄이지 않는 것**이다.
매일 계획·거래할 수 있지만 거래를 강제하거나 주 1회로 제한하지 않는다.

## 1. 분석·매수·점검은 서로 다른 시간이다

요청을 받으면 그때 분석한다. 아침 요청에 오후 재접속을 요구하지 않으며, 장중 요청도 실행 가능한 남은 세션을 활용한다.
가격표는 종목별 진입가·익절가·손절가 각 하나로 단순하게 유지한다. 여러 번 가격을 바꾸도록 요구하지 않는다.

| 구분 | 새 기본 운영 |
| --- | --- |
| 신규 매수 입력 | 확인된 거래일 09:00부터 14:30 전까지 중 편한 때 한 번 |
| 접수된 매수 주문 | 지정가를 유지하며 당일 취소 시각까지 대기 가능 |
| 미체결 잔량 정리 | 15:00 취소 요청, 완료와 취소 중 추가 체결까지 확인 |
| 보유 점검·필요 청산 | 15:00~15:15 기본 시간대. 매수 시간 제한이 아님 |
| 신규 매수일 첫 점검 | 그날 실시. 첫 점검을 다음 날로 생략하지 않음 |
| 분석 빈도 | 사용자 요청 시 한 번. 장전·장중·장후 가능 |

09:00~14:30은 운영 기본값이지 거래소 규정·유일한 시간대가 아니다. 개별 계획은 실제 시장 시간과 절대 날짜를 명시한다.
늦은 장중 요청에는 실행·취소·대사를 마칠 수 있는 남은 구간을 사용할 수 있다. 충분한 시간이 있는데 임의로 5~10분만 허용하지 않는다.
짧은 유효시간이 꼭 필요하면 이유를 쓴다. 시작 시각을 놓쳐도 아직 입력 구간 안이고 무효 사유가 없다면 한 번 입력할 수 있다.
마감 후 주문·다음 날 자동 재사용·소급 입력은 하지 않는다.

신규 매수일은 **입력할 때와 나중에 점검할 때** 앱을 여는 작업이 필요하다. 보유만 하는 날은 한 차례 점검을 기본으로 한다.
한 번의 클릭이나 정해진 시간 안의 전량 체결·취소 완료를 보장하지 않는다. 체결·취소 지연이면 완료까지 추가 확인이 필요할 수 있다.
15시 기본 점검 자체는 새 계획에서 변경할 수 있지만, 알려진 실행 가능 시간과 위험 수용을 확인 없이 없애지는 않는다.

## 2. 넓은 진입 시간은 무인 손절이 아니다

주문 입력 직전 실제 가격이 손절 이하·익절 이상이거나 알려진 거래 제한·가설 무효·중복 주문 문제가 있으면 입력하지 않는다.
그러나 **일반 지정가 매수는 접수 후 가격이 손절선을 통과하거나 새 악재가 나와도 자동 취소되지 않는다.**
확인하지 않는 동안 매수된 뒤 더 하락하거나 손절선 아래에서 체결될 수 있다. 이 위험을 설명하고 가능한 최초 체결부터 점검까지 수량에 반영한다.
입력 전 조건 검사를 장중 상시 자동 감시처럼 설명하지 않는다. 알려진 무효 사유를 실제 확인했다면 매수 잔량 취소를 우선한다.

점검 때 잔량 취소 완료를 확인하고 그 사이 생긴 추가 체결·부분 체결·실제 보유를 대사한다.
그날 체결분에도 기존 청산 기준을 적용한다. 취소·점검 뒤 새 매수를 추가하지 않는다.
점검을 놓쳤다면 다음 실제 확인 때 보유·미체결부터 대사하고 그 전 신규 진입을 보류한다.
일반 주문의 자동 익일 승계·GTC·무인 취소는 검증되지 않았으므로 가정하지 않는다.

## 3. 가격과 보유기간도 구분한다

실행 가능성을 검토하지 않은 깊은 눌림·과거 최저가 주문만 반복하지 않는다.
관측 가격과의 거리, 변동성·호가·유동성·비용 후 손익 구조를 함께 보며 근거가 있으면 확인된 매도호가 부근의 지정가도 선택할 수 있다.
이는 무조건 비싸게 사겠다는 뜻이 아니다. 매수 상한은 한 번 정하고 추격 정정·무조건 시장가 전환을 하지 않는다.
진입가 변경은 새 버전의 가격 재산정이며 입력 시간 연장과 별개다. 체결 확률·기대수익을 근거 없이 만들지 않는다.

수일 보유를 우선한다. 2~5거래일은 선호 구간이지 강제 기한이 아니다. 실제 기한은 종목·상품 구조·변동성·이벤트·대회 일정을 반영한다.
진입 시간을 넓히려고 기존 손절가를 낮추거나 기한을 늘리지 않는다. 손절폭을 넓히는 새 계획은 수량도 다시 산정한다.
`config/planning.json`의 기존 노출·손절·스트레스 예산은 유지한다. 거래가 없었다는 이유로 위험 한도를 늘리지 않는다.

## 4. 청산 평가 방식

가격표에 입력 가능 구간과 별도로 `exit_evaluation_mode`, `manual_window`, `first_review_at`, `review_at`, `next_review_at`을 쓴다.
시간대·지연 대응 위험은 이미 확인된 설정을 재사용하며 새로운 충돌이 있을 때만 필요한 사실을 확인한다.

### 정시 확인형: scheduled_review

사용자가 계획한 점검 시각에 실제 관측한 가격으로 판단한다. 손절 이하이면 시장가, 익절 이상이면 익절 지정가로 잔여수량을 청산한다.
기한이 먼저 오면 시간 청산하며 동시에 확인되면 손절 → 시간 청산 → 익절 순이다. 기존 주문 취소·잔량 대사 후 실제 수량만 사용한다.
익절 지정가 미체결의 처리 방식과 시각은 개별 계획에 사전 명시한다.

점검 사이 잠깐 가격을 통과한 것만으로 자동 체결·소급 발동하지 않는다. 확인한 청산 사유는 반등을 이유로 지우지 않는다.
15:00/15:10의 관측은 종가가 아니다. 실제 종가를 본 뒤 같은 종가에 체결했다고 소급하지 않는다.
추가로 중대한 위험을 알게 되면 신규 진입 중단과 별도 대응을 검토하되 상시 감시자가 있다고 가정하지 않는다.

### 검증된 앱 조건 주문형: verified_native_conditional

대회 모의계좌에서 실제 지원되는 경우에만 쓴다. 지원 근거·관측 시각·감시 시간·유효기간·앱 종료 동작·부분체결·OCO/충돌 처리를 검증한다.
실계좌 지원을 대신 쓰지 않는다. 일반 매도 지정가 두 개는 손절·익절 OCO가 아니며 낮은 일반 매도 지정가는 손절 대기가 아니다.
손절가는 보장 체결가·손실 상한이 아니다. 코드·문서 수정으로 주문·자동 손절 기능이 생기지 않는다.

## 5. 기존 계획 변경

변경은 신규 계획 또는 명시적으로 버전을 올린 수정본에만 적용한다. 기존 보유의 발동 손절·시간 청산은 먼저 대응한다.
미진입 계획의 시간만 넓혀도 실제 주문·체결 상태와 더 이른 체결 위험, 매수 당일 첫 점검을 검토한다.
원래 가격·수량·기한의 유지 또는 변경 범위를 분명히 적고 원본은 보존한다. 가격 전망 재검토와 시간 변경을 혼동하지 않는다.
정책 변경·문서 만료·새 버전은 앱 주문 취소가 아니다. 실제 취소 완료 전 자금·수량을 재사용하지 않는다.

## 6. 매매회전율 500%의 해석과 한계

저장소의 매뉴얼 요약(`docs/rules.md`, 원문 p.17·19)에는 회전율 500% 이상, 체결 5종목 이상, 매매일수 5영업일 이상이 함께 기록돼 있다.
이는 수익률 500% 요건이 아니다. `config/competition.json`의 `award_requirements.turnover_formula`는 미확인(null)이다.
2026-09-11 조사에서 정확한 공식 산식을 추가 확보하지 못했다는 기존 기록을 유지한다.
기준자산이 원금인지 평균 평가자산인지, 매수·매도 합산인지 한쪽인지 평균인지 임의로 확정하지 않는다.

아래는 **기준자금 1억 원, 손익·비용 생략의 산술 예시이며 공식 산식이 아니다**.

| 가정한 산식 | 500%에 필요한 거래금액 | 2,500만 원 매수 후 같은 금액 매도 1회 | 같은 규모 왕복 환산 |
| --- | --- | --- | --- |
| (누적 매수 + 누적 매도) / 1억 원 × 100 | 매수·매도 합계 5억 원 | 50%포인트 | 10회 |
| ((누적 매수 + 누적 매도) / 2) / 1억 원 × 100 | 매수·매도 합계 10억 원 | 25%포인트 | 20회 |
| 누적 매도 / 1억 원 × 100 | 매도 누계 5억 원 | 25%포인트 | 20회 |

이는 거래 규모 설명이지 반복 거래 지시가 아니다. 같은 자금을 재사용할 수 있어 그만큼 새로 입금하라는 뜻도 아니다.
한 종목 반복 거래는 서로 다른 5종목 요건을 대신하지 못한다. 당일 왕복이어야 한다는 조건을 추가하지 않는다.
회전율만을 위한 형식적·비경제적 매매나 불공정 거래 제한 우회를 하지 않는다.
공식 진행도는 앱 값과 관측 시각만 쓴다. 주문 입력·취소·가격 도달을 체결로 세거나 정산 화면으로 전체 기간 회전율을 추정하지 않는다.
공식 산식이 확인되면 출처·원문·확인일과 설정을 먼저 갱신하고 추정치와 구분한다.

## 7. 출처와 변경 범위

- [iM증권 거래시간](https://www.imfnsec.com/mobile/cs/cs0201.jsp): KRX 일반 정규장 안내. 모의계좌의 세부 지원·자동 주문 검증을 대신하지 않는다.
- [Investor.gov Limit Orders](https://www.investor.gov/introduction-investing/investing-basics/glossary/limit-orders): 일반 지정가 원리.
- [Investor.gov Stop Order](https://www.investor.gov/introduction-investing/investing-basics/glossary/stop-order): 일반 손절 주문 원리.

일반 안내 확인일: 2026-09-14. 실행 당일 시장·모의계좌의 제한은 개별 계획에서 확인한다.
이 문서는 계획 지침이지 자동 감시·알림·주문·취소·예약 작업이 아니다.
공개 저장소에는 일반 운영 지침·빈 양식만 두고 개인 식별자·화면·실제 잔고·개별 주문은 올리지 않는다.
