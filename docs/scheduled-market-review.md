당시 검증 계획은 진단 응답이 끝난 뒤 실제 예약으로 정상 시장 점검을 한 번 수행하고, 시작 시 교정한 정상 장중 20분 간격을 복원하는 것이다. 점검 시작·종료 토큰 마커로 진단 비용을 분리하고, 다음 예약에서 직전 완료 턴의 전체 토큰을 확인하도록 했다. 검증 중에는 결과를 사용자에게 알린다. 실제 실행·사용량 관측 전에는 검증 성공으로 표시하지 않는다. 기존 진단·설정 기록은 보존하고 정정 이벤트를 추가한다.

## 점검과 사용자 행동

공개 KRX 시세·거래량·시장폭·업종·뉴스·공시를 수집하고, 최신 로컬 보고·기존 지시 상태를 읽어 판단한다. 계좌 화면은 조회하지 않는다. 사용자 계좌 보고 없이 잔고·체결·미체결 상태를 새 관측으로 만들지 않는다. 최종 결정과 지시 발행자는 현재 대화의 AI 하나다.

변화 없는 HOLD는 원본과 블로그 기록을 남기고 반복 알림을 하지 않도록 설정했다. 의미 있는 판단 변화, 입력용 주문 지시, 새 위험, 조사 실패 또는 필요한 계좌·주문 보고가 생길 때 이 대화로 알린다. 같은 미해결 문제는 새로운 사실이나 시한이 없으면 반복하지 않는다. 매 거래일 첫 계좌 확인이 없을 때는 필요한 자료를 한 번 요청한다.

사용자는 계좌 조회, 주문 입력·정정·취소, 접수·체결·잔량·비용 보고를 계속 맡는다. 실제 지시는 입력 조건·입력 마감·미체결 확인·취소 계획을 구별해야 한다. 지시를 늦게 확인하면 만료된 주문을 입력하지 말고 최신 상태를 보고한다. 이미 접수된 주문은 입력 기한이 지나도 취소된 것으로 보지 않는다. 알림 도착과 즉시 응답을 전제로 가격·수량을 정하지 않는다.

판단 시작 때와 지시 발행 직전에 최신 결정·활성 지시·보고를 다시 확인하도록 지시했다. 결과 미보고 중에는 충돌할 새 지시를 보류한다. 신규 주문에는 120초 이내 KRX 가격과 당시 종목 제한·현금·보유·주문가능수량 검사를 유지한다. 이 절차를 강제하는 별도 자동 주문 검증 프로그램이나 잠금 기능이 구현됐다는 뜻은 아니다.
