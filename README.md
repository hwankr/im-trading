**현재 상태: 12:20:06 KST 첫 주문 전량 미체결 취소 확정, 체결0주·잔량0주.** 사용자의 입력·전부취소·최종0/0 보고로 첫 지시를 마감했다. 활성 지시는0건이며 신규·대체 주문은 없다. 현금1억원과 주문가능53주는11:56의 과거 보고이고 취소 후 현재값으로 갱신하지 않는다. 다음 앱 점검 예정은 12:31:35 KST다.

## 운영 목표

**장중 예약이 활성화되어 실제 시장 점검을 수행하고 있다.** 시간 해석 오류를 정정한 뒤 2026-09-08 10:45:49 KST 첫 자동 호출을 확인했고, 10:56:44에 해당 작업을 완료했다. 정상 장중 20분 간격 설정을 복구했으며 실제 예정·호출 시각은 각각 기록한다. 첫 실행 전체 사용량은 1,214,003토큰(입력 1,200,674, 그중 캐시 1,124,096, 출력 13,329)이다. 첫 복구·기록 작업을 포함한 값이며 비용이나 구독 한도 소모율로 환산하지 않는다. 변화 없는 HOLD는 기록만 남기고 의미 있는 변화·사용자 조치·시한 도래 때 알린다. 계좌 조회와 주문 입력·정정·취소·결과 보고는 사용자 담당이다. 컴퓨터와 앱이 켜져 있어야 하며 정시 실행·알림을 보장하지 않는다. [예약 운영 상세](docs/scheduled-market-review.md)를 참조한다.

대회 규정과 수상 조건을 충족하는 범위에서 최종 공식 수익률을 최대화한다. 종목, 투자 스타일, 현금 비중, 매매 빈도, 추가 위험 한도는 AI가 근거를 남기고 결정한다. 수익률과 별도로 시장 대비 성과·최대 낙폭·운영 비용·사람의 개입을 기록한다.

운영 흐름은 **사용자가 계좌 상태 전달 → AI가 시장 조사·검토 후 주문 지시서 발행 → 사용자가 지시대로 앱에 입력 → 접수·체결 결과 전달 → AI가 장부와 다음 판단 갱신**이다. 투자 의견 개입과 조회·입력 보조를 별도로 기록한다.

사용자의 확인에 따라 이 프로젝트는 증권사 API 없이 운영한다. iM증권의 모든 API 제공 여부를 독립적으로 확인한 결론은 아니다. 다음 작업은 **첫 주문의 미체결 취소 결과를 유지한 채 새 시장 자료와 계좌 자료의 유효성을 검토하는 것**이다. 최신 투자 실행 명세는 `decision-manifest-0010.json`이다. 예약 운영 변경, 투자 판단 변경, 주문 발행과 실제 결과는 각각 별도 기록으로 남긴다. 이전 검토 가격으로 돌아오더라도 자동으로 매수하지 않는다. 향후 매수 전에는 최신 종목 제한과 앱 주문가능수량을 다시 검토한다. 계좌 보고·입력·정책·결정은 Git에서 제외한 `runs/im-rookie-2026-paper-main/`에 저장한다. 기존 스냅샷을 보존하며 예약 등록과 실제 실행 성공을 구분한다.

## 블로그 기록

작업이 끝날 때마다 AI가 공개용 Markdown 기록과 당일 초안을 작성한다. 권장 발행 방식은 **시작 글 1편 → 주간 결산 → 중요한 변화가 있는 날의 일간 글 → 최종 회고**다. 사용자가 제목과 본문을 티스토리에 복사해 발행한다.

- [기록 규칙·원고 목록·복사 방법](blog/README.md)
- [첫 게시글 본문: AI에게 가상 원금 1억 원의 투자 판단을 맡겨보기](blog/posts/2026-09-08-00-experiment-start.md)
- [9월 8일 장중 초안](blog/daily/2026-09-08.md): 첫 주문의 미체결 취소 대사까지 담은 장중 기록이며 마감 성적이 아니다.

원본 투자 기록과 공개 글의 근거를 연결하고, 블로그 편집·독자 반응은 매매 판단에 섞지 않는다. 예약 점검에서 실제 완료한 조사·판단도 원고로 남기며, 블로그 발행은 사용자가 맡는다.

수집 작업 주의: 기록 번호를 전체 문자열 치환하면 종목 코드까지 바뀔 수 있다. 경로·기록 식별자만 정확히 바꾸고 의도한 종목 코드와 이름을 확인한다. 이번 정정은 로컬 `inputs/symbol-correction-0007.json`에 보존했다.

지시의 활성 여부는 파일 존재로 판단하지 않는다. `instructions.jsonl`에서 각 지시 ID의 최신 상태와 결과 보고를 확인한다. 첫 지시는 CLOSED이며 원래 ISSUED 기록은 보존돼 있다.
