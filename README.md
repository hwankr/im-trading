# iM 모의투자 · 고정 진입가 / 청산가

**요청 시 한 번 분석해, 살 가격과 나올 가격을 먼저 정한다.**
실시간 대응이나 장중 조건 추적 대신 종목별 **진입가 1개 · 익절가 1개 · 손절가 1개**를 제시한다.
현재 저장소는 AI 운영 지침·설정·기록 양식이다. 시세 수집기·주문 프로그램·자동 손절 기능은 구현되어 있지 않다.

## 이렇게 요청한다

> 오늘 기준으로 종목별 진입가, 익절가, 손절가를 정해줘.

장전뿐 아니라 장중·장후에도 요청할 수 있다. 요청 시점에 확인한 시장 자료로 한 번 판단하며,
이후 가격을 자동으로 따라 바꾸거나 실시간으로 지켜보지 않는다. 장후·휴장일에는 다음 거래 가능 시간을 확인한다.

결과는 아래 순서로 나온다. 아래 빈 양식은 실제 추천이나 주문이 아니다.

| 종목 / 코드 | 진입가 | 익절 청산가 | 손절 기준가 | 수량 | 진입 마감 | 청산 기한 |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| 분석 후 확정 | — | — | — | 계좌 미확인 시 미산정 | 날짜·시각 KST | 날짜·시각 KST |

표 다음에는 종목별 짧은 근거, 비용 전 기대수익률·손절폭·손익비, 출처·자료 시각만 덧붙인다.
신규 후보는 기본 최대 3개다. 기존 보유는 별도 청산표에 빠짐없이 표시한다.
"거래량을 더 보고", "5분 뒤 다시 판단", 여러 가격대 중 사용자 선택 같은 지시는 기본 절차에서 제외한다.

## 실행 원칙

진입가 이하에서만 지정가 매수하며, 미진입 상태에서 이미 손절가 이하이거나 익절가 이상이면 해당 진입은 무효다.
진입 기한이 지나면 신규 입력을 중단하고 접수된 미체결 잔량은 사용자가 취소·확인한다. 비싸게 추격하지 않는다.
체결 후에는 익절가·손절가·명시한 청산 기한 중 먼저 발생한 사유로 잔여 보유를 청산한다.
부분 체결이면 실제 매도가능수량만 적용한다. 전량 청산 후 같은 계획으로 재진입하지 않는다.

**가격은 고정되지만 체결 가격과 수익은 보장되지 않는다.** 손절·익절·취소는 사용자가 확인하고 실행한다.
자동 감시·자동 주문·자동 알림은 없으며, 확인하지 않는 동안 갭이나 급변으로 기준가를 놓칠 수 있다.
앱의 자동 조건 주문 지원은 확인되지 않았다. 일반 매도 주문 두 개를 OCO처럼 취급하지 않는다.

## 계좌가 없어도 가격부터

가격 근거가 충분하면 계좌 파일 없이도 `PRICE_ONLY` 가격표를 제공한다. 이때 수량·투입금은 미산정이며 완성된 주문 지시가 아니다.
수량까지 필요한 경우 확인 시각, 모의계좌 여부, 현금·주문가능금액, 전체 보유·매도가능수량, 미체결과 최근 체결/취소 사실을 사용한다.
같은 대화에서 이미 확인한 사실을 다시 묻지 않는다. 과거 보고의 시각을 현재로 바꾸거나 1억 원을 현재 잔고로 간주하지 않는다.

`READY`는 가격·수량·기한·실행 검토가 갖춰진 계획, `HOLD`는 비매매 판단, `BLOCKED`는 핵심 근거 부족이다.
가격표를 확정했다고 계좌나 주문이 바뀌지 않는다. “체결 내역을 반영해줘”라는 보고에는 계좌만 대사하고 기존 가격을 유지한다.
가격을 다시 정할 때는 “새 기준으로 다시 계산해줘”라고 명시한다. 새 버전도 기존 앱 주문을 자동 취소하지 않는다.

## 파일 지도

```text
AGENTS.md                         AI 작업 원칙과 가격표 우선 출력 계약
config/planning.json              고정 가격 계획의 운영 설정 (대회 규칙 아님)
config/competition.json           대회 원문 규칙과 미확정 항목
prompts/plan.md                    시간대 공통 가격 산정 절차
prompts/premarket.md               기존 장전 요청의 호환 진입점
prompts/reconcile.md               체결·계좌 대사 (가격 변경 없음)
templates/day.md                   가격표 + 계획 근거 + 체결 기록
templates/account.json            비공개 계좌 요약의 초기 양식
docs/rules.md                      규칙 요약과 원문 페이지
docs/migration.md                  전환 이력과 백업·외부 작업 주의
docs/sources/competition-manual.pdf 원본 매뉴얼
```

평소에는 AGENTS·운영 설정·대회 설정·해당 프롬프트와 필요한 계좌/계획만 읽는다.
비공개 로컬 기록을 준비할 때만 다음을 사용한다. 기존 계좌 파일은 덮어쓰지 않는다.

```sh
mkdir -p data/days
test -e data/account.json || cp templates/account.json data/account.json
```

`data/account.json`은 최신 확인 사실, `data/days/YYYY-MM-DD.md`는 계획과 후속 보고를 보관한다.
`null`은 미확인, `[]`는 확인된 보유/미체결 없음이다. 비공개 로컬 파일에 접근할 수 없으면 응답만 제공한다.
**data/와 기존 runs/는 Git에서 제외된다.** 공개 저장소에 계좌·개인 화면·당일 계좌 기록을 올리지 않는다.

전환 전 상태는 `archive/pre-fixed-price-20260910`, 더 이전 운영은 `archive/pre-premarket-20260908`에 보존한다.
자세한 이력은 [이전 안내](docs/migration.md)를 확인한다. Git 백업은 비공개 로컬 기록을 포함하지 않으며,
저장소 수정만으로 외부 예약이나 앱 미체결 주문이 중지·취소되지는 않는다.
