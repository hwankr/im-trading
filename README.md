# iM Rookie League AI 투자 실험

사용자의 종목 추천, 시장 전망, 매매 의견을 입력하지 않고, AI가 시장 조사와 포트폴리오 결정을 수행했을 때의 모의투자 성과를 기록하는 프로젝트다. **계좌 조회와 주문 입력·정정·취소는 사용자가 담당한다.**

**현재 상태: 09:49:00 KST 세 번째 AI 판단도 현금 유지(HOLD), 누적 발행 주문 0건.** 초기 계좌의 현금 주문가능금액은 1억 원, 보유·미체결·이전 거래 없음으로 확인됐다. 08:50:15와 09:28:32의 HOLD 이후 반도체와 원전·건설·전기유틸리티·조선 후보를 다시 비교했다. 09:44 KRX 관측에서 코스피는 상승했지만 코스닥은 하락했고, 09:43에는 두 시장 모두 하락 종목이 더 많았다. 하이닉스의 상대 강세와 현금 보유의 기회비용을 인정하면서 새 주문을 내지 않았다. 초기 계좌는 조건부 이어 사용했으며 새 조회나 체결을 가정하지 않는다.

## 운영 목표

**장중 예약 조회 활성화 — 첫 예정 점검: 2026-09-08 10:10 KST.** 이제 정기적으로 `투자 판단 진행해줘`라고 보내지 않아도 된다. 실제 거래일 09:10~15:10 KST에 20분 간격으로 시장을 확인하도록 현재 대화에 예약을 등록했다. 변화 없는 HOLD는 기록만 하고, 의미 있는 변화·입력용 지시·자료 실패·필요한 계좌 또는 주문 보고가 생길 때 알리도록 했다. 계좌 조회와 주문 입력·정정·취소·결과 보고는 계속 사용자 담당이다. 현재 입력할 주문은 없다. 컴퓨터와 Codex 앱이 켜져 있어야 하며 실행·알림 시각은 보장하지 않는다. 등록과 일정은 확인했으나 첫 자동 실행의 성공은 아직 확인 전이다. [예약 운영 상세](docs/scheduled-market-review.md)와 로컬 `operations/automation-setup-0001.json`, `operations/automation-update-0001.json`에 설정을 보존했다.

대회 규정과 수상 조건을 충족하는 범위에서 최종 공식 수익률을 최대화한다. 종목, 투자 스타일, 현금 비중, 매매 빈도, 추가 위험 한도는 AI가 근거를 남기고 결정한다. 수익률과 별도로 시장 대비 성과·최대 낙폭·운영 비용·사람의 개입을 기록한다.

운영 흐름은 **사용자가 계좌 상태 전달 → AI가 시장 조사·검토 후 주문 지시서 발행 → 사용자가 지시대로 앱에 입력 → 접수·체결 결과 전달 → AI가 장부와 다음 판단 갱신**이다. 투자 의견 개입과 조회·입력 보조를 별도로 기록한다.

사용자의 확인에 따라 이 프로젝트는 증권사 API 없이 운영한다. iM증권의 모든 API 제공 여부를 독립적으로 확인한 결론은 아니다. 다음 작업은 **첫 예약 실행에서 새 KRX 가격·거래량과 상승 참여 종목의 확산 여부로 진입 조건을 재평가하는 것**이다. 최신 투자 실행 명세는 `decision-manifest-0003.json`이며 이번 예약 설정은 투자 결정을 바꾸지 않은 운영 변경이다. 이전 검토 가격으로 돌아오더라도 자동으로 매수하지 않는다. 향후 매수 전에는 최신 종목 제한과 앱 주문가능수량을 다시 검토한다. 계좌 보고·입력·정책·결정은 Git에서 제외한 `runs/im-rookie-2026-paper-main/`에 저장한다. 기존 스냅샷을 보존하며 예약 등록과 실제 실행 성공을 구분한다.

## 블로그 기록

작업이 끝날 때마다 AI가 공개용 Markdown 기록과 당일 초안을 작성한다. 권장 발행 방식은 **시작 글 1편 → 주간 결산 → 중요한 변화가 있는 날의 일간 글 → 최종 회고**다. 사용자가 제목과 본문을 티스토리에 복사해 발행한다.

원본 투자 기록과 공개 글의 근거를 연결하고, 블로그 편집·독자 반응은 매매 판단에 섞지 않는다. 예약 점검에서 실제 완료한 조사·판단도 원고로 남기며, 블로그 발행은 사용자가 맡는다.
